# Clairity

Clairity is a private personal wellbeing app designed to help one person understand the relationships between sleep, nutrition, symptoms, behaviour, activity and health over time.

## Vision

Clairity is not a calorie tracker or habit tracker.

Its purpose is to build clarity by collecting evidence and identifying patterns while respecting uncertainty.

## Principles

- Private by default
- Minimal effort
- Autosave everything
- Evidence before conclusions
- Adaptive to the user's state
